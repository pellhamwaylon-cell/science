# 🔬 Middlanders Science Study & Interactive Encyclopedia

An interactive, single-page-application style digital study book and encyclopedia covering middle school science (NGSS aligned for 7th & 8th grade).

## 🚀 Live Demo & Hosting
This project is designed to be hosted directly on **GitHub Pages**.
- **Root Entry:** `index.html`
- **Zero External Dependencies:** Built with native HTML5, CSS3, JavaScript, Web Audio API, and local IndexedDB caching.

## 📂 Repository Structure

### Core Landing & Hub
- `index.html` - Master dashboard, grade curriculum toggles, and navigation portal.
- `README.md` - Repository documentation.

### 🌿 7th Grade Science Core Modules
- `science_study_file_1_scientific_inquiry.html` - MV, RV, and CV variables guide.
- `science_study_file_2_lab_design.html` - Experimental design & hypotheses.
- `science_study_file_3_matter_and_atoms.html` - Atomic structure & periodic table.
- `science_study_file_4_energy_and_forces.html` - Thermal energy, phase changes, and forces.
- `science_study_file_5_cells_and_life.html` - Cell organelles, plants, and fungi.
- `science_study_file_6_ecosystems.html` - Food chains, webs, and energy pyramids.
- `science_study_file_7_environmental_science.html` - Human impact & resource management.

### 🛠️ Interactive Tools & AI Hubs

- `science_study_file_10_virtual_lab.html` - Interactive physics & chemistry simulations.
- `science_study_file_11_science_encyclopedia.html` - Searchable visual encyclopedia.
- `science_study_file_12_achievement_system.html` - XP and study streak tracker.
- `science_study_file_13_data_analysis_lab.html` - Graphing & data plotting workbench.
- `science_study_file_14_science_challenges.html` - Problem-solving scenario solver.
- `science_study_file_15_ai_tutor.html` - Local prompt-assisted study helper.
- `science_study_file_16_app_launcher.html` - Quick launcher for all integrated tools.
